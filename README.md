# API Basics — CRUD API

A simple REST API built with **Python and FastAPI** to practice CRUD operations and understand how APIs work.

## 🚀 Features

- Create data — `POST`
- Read data — `GET`
- Update data — `PUT`
- Delete data — `DELETE`
- FastAPI automatic API documentation
- Input validation with Pydantic

## 🛠️ Tech Stack

- Python
- FastAPI
- Uvicorn
- Pydantic
- uv

## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/faizanuddinkhan7/API_Basics.git
cd API-Basics
```

Install dependencies:

```bash
uv sync
```

## ▶️ Run the API

```bash
uv run main.py
```

The API will be available at:

```text
localhost:8000
```

## 📚 API Documentation

FastAPI automatically provides interactive documentation.

Swagger UI:

```text
localhost:8000/docs
```

ReDoc:

```text
localhost:8000/redoc
```

## 🔄 CRUD Operations

| Method | Purpose |
|---|---|
| `POST` | Create a resource |
| `GET` | Read resources |
| `PUT` | Update a resource |
| `DELETE` | Delete a resource |
